# SilkShine Management Android App

A comprehensive React Native application built with **Expo** designed specifically for managing inventory, tracking stock, handling product calculations, and supporting localized themes and languages for a silkshine oil selling business.

## **Key Features**

* **Stock Management:** Track real-time inventory levels, monitor stock updates, and prevent shortages for various oil variants.
* **Product & Price Calculations:** Built-in calculation tools for pricing, volume measurement, and order total summaries.
* **Theme & Language Support:** Customizable UI themes and multi-language support to suit diverse user preferences.
* **State Management & Local Storage:** Uses React Context API for global state management and local storage solutions to persist user data, settings, and offline records.

## **Tech Stack**

* **Framework:** React Native / Expo
* **State Management:** React Context API
* **Storage:** AsyncStorage (or local storage equivalent)
* **Platform:** Android / Cross-Platform

## **Getting Started**

### **Prerequisites**

Make sure you have the following installed on your machine:

* Node.js (LTS recommended)
* npm or Yarn
* Expo Go app on your mobile device (or an Android emulator)

### **Installation & Setup**

1. Clone the repository:
```bash
git clone https://github.com/mukhtar-x/SilkShine-Management-Android-App.git
cd SilkShine-Management-Android-App

```


2. Install dependencies:
```bash
npm install
# or
yarn install

```


3. Start the Expo development server:
```bash
npx expo start

```


4. Scan the QR code using the Expo Go app on your Android device or press `a` to open the Android emulator.
